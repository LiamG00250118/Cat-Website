# Claude Code Configuration

This file contains configuration and guidelines for working with Claude Code on the Cat-Website project.

## Overview

This is a Cat-Website project. Claude Code can assist with development tasks, bug fixes, feature implementation, and code improvements.

## Development Guidelines

- Make commits with clear, descriptive messages that explain the why, not just the what
- Follow the existing code style and conventions
- Test changes before pushing
- Keep commits focused and atomic

## Project Structure

This repository contains the Cat-Website project. As the project develops, update this file with:
- Project setup instructions
- Development environment requirements
- Testing procedures
- Build and deployment processes

## Asking Claude Code for Help

You can ask Claude Code to:
- Implement new features
- Fix bugs
- Refactor code
- Explain implementation details
- Run tests and build processes
- Review and optimize code

## Notes

- All development should occur on the designated feature branches
- Push changes to the appropriate branch when ready
- Use clear commit messages for all changes
